TIC TAC TOE — PC VERSION
========================

HOW TO PLAY
-----------
1. Double-click tic-tac-toe.html — it opens in your browser (Chrome/Edge/Firefox).
2. Nothing to install, no internet needed, no server needed.
3. Type both players' names, then take turns clicking the squares.
   X goes first. First to get 3 in a row wins!

FEATURES
--------
- Two-player mode (play with a friend on the same PC) — the default
- Play vs Computer mode too (Easy / Medium / Hard), with a choice of X or O
- Player names shown on the scoreboard and in the turn messages
- Scoreboard: wins for X, wins for O, and draws
- Winning line highlighted with a gold strike line
- Draw detection
- New Round (keeps the score), Reset Score, and Full Reset buttons
- Sound effects with an on/off button, and confetti when someone wins

This is a standalone copy of the Tic Tac Toe game from Muse.
